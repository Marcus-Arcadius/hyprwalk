Conventions:
- **U** is each GameObject's Unity world matrix in meters. The avatar root's translation is zeroed and the stand-up R is applied.
- **to_unity(M, u)** is `FLIP@AXIS@M@FLIP` with the 3×3 divided by u; from_unity is its inverse. A Unity point p has glTF world position `FLIP @ U @ p`.
- **Armatures:** every FBX becomes its own Blender armature, with one skin per armature and every bone a joint. Skinned mesh nodes sit under their armature.
- **The plugin** (src/avatar.cpp, nodes() around lines 1447 to 1496):
  - It skins with `restGlobal[joint.node]·inverseBind` and ignores both the mesh node transform and skin.skeleton.
  - It orders nodes by a DFS preorder from the scene roots, so glTF node order doesn't matter. Reindex only when deleting nodes.
  - Duplicate joints are fine.

## Design (decided: option B)

### 1. class ModularAvatar

Signature: `ModularAvatar(av, human_all, U, outfits=())`. Put it after adopt() and before the space helpers.

It runs right after `b.compute(human)` and mutates b.U in place, so U ends up holding the final, post-MA Unity worlds. Blender's arrange and place then use those U with the ORIGINAL parent hierarchy.

**State:**
- `parent` {id: GO or None} and `kids` {id: [GO]}, copied from the original tree. Child order matters.
- `nm` {id: name}, so Find works on mangled names (`name$<n>`).
- `deleted` (a set) and `retarget` {id(src): dest}.
- `dead`: a set of PB component ids.
- `blocks` {id(PB root GO): [tips]} and the `pbblock` set.
- `vparent` {id: the new parent of a bone-proxied GO}.
- `U0`: a copy of U from before MA.

**Helpers:**
- `find(t, path)`: Transform.Find on the post-MA tree. Split on '/', skip empty parts, handle '..', and match direct children by name in order.
- `objref(r)`: resolves an AvatarObjectReference on the ORIGINAL tree.
- `set_parent(g, p)`: appends g to p. U stays unchanged, which keeps the world transform.
- `similar(a, b, ignores)`.
- `thisPassAdded` and `orig_parent`.
- An insertion-ordered bone db with add, retain and retargeted.
- A ref scan: recurse over component data and skip m_GameObject. An Obj with cls in TRANSFORMS maps to its .go; cls 1 maps to itself.

**At the end:** give each deleted GO s with dest d `U[s] = U[d] @ U0[d]⁻¹ @ U0[s]`, so Blender places deleted bones rigidly with their dest.

**Warnings:**
- MA components that aren't emulated: ReplaceObject, BlendshapeSync, MaterialSetter, MaterialSwap, VisibleHeadAccessory, MeshSettings.
- Targets that are unresolved or invalid.

### 2. ma.apply(js, binc) -> binc

Call it after patch_materials and before Settings. It edits the GLB using the exported worlds from gltf_tree:

- **(a) Re-parent.** A node moves when its post-MA GO parent differs, or when its GLB parent is being deleted. Keep its world: `local = W(newParent)⁻¹ · W(n)`, decomposed to TRS. A node with no surviving ancestor becomes a scene root.
- **(b) Retarget skin joints.** Joints of retargeted GOs move to the dest's node, or to the nearest surviving post-MA ancestor, with `IBM' = W(n_dest)⁻¹ · W(n_src) · IBM`.
  - Write a new MAT4 accessor and a 4-byte-aligned bufferView appended to binc.
  - Update buffers[0].byteLength and drop skin.skeleton.
  - A bone that is retargeted but not deleted, because it has a non-MA component, keeps its node. Joints pointing at it are still retargeted.
- **(c) Delete.** Remove the nodes of deleted GOs and reindex scenes, children and joints.

### MergeArmatureHook

**Setup:**
- `physBoneByRootBone[rootTransform ?? go]` covers every PB, inactive ones included, in preorder. The last one wins.
- `humanoidBones` is every human bone transform of the avatar except LastBone.

**Topo order:** for each config:

    parentConfig = target.GetComponentInParent<MergeArmature>()
    runsBefore[parentConfig].Add(config)

So a config whose target lies inside another MergeArmature's hierarchy merges first. A cycle is fatal. All MergeArmature components are destroyed once every merge is done.

**Each config:**
1. `while IsRetargetable(target)` (db value True): `target = target.parent`.
2. Clear prune and thisPassAdded.
3. `RecursiveMerge(config, config.go, target, zip=True)`.
4. Run PruneDuplicatePhysBones.

**After all configs:**
- RetainMergedBone for every bone proxy and target in TargetMapping.
- For VRCPhysBone, VRCPhysBoneCollider and Contact: set rootTransform to self if it's null, then RetainBoneReferences.
- For VRC and Unity constraints: RetainBoneReferences. It walks the serialized properties, skips strings and m_GameObject, and retains every Transform or GameObject it finds.
- **The SMR rootBone check:**
  - Skip it if rootBone or rootBone.parent is null.
  - Otherwise take root = rootBone and parent = root.parent after the merge.
  - Retain root if `(parent.position-root.position).sqrMagnitude > 1e-6` or `Dot(parent.localScale.normalized, root.localScale.normalized) < 0.9999`.
- Then RetargetMeshes.

### RecursiveMerge(config, src, newParent, zip)

1. If src == newParent, return.
2. If zip, add src to thisPassAdded.
3. Set `zip = zip and src has no constraint`. Ignore the constraint dummy and intermediate objects.
4. `src.SetParent(newParent, worldPositionStays=true)`.
5. If mangleNames is set (default true), rename src to `name$<guid>`.
6. GetOrAdd a PBBlocker on src.
7. Check its PhysBone:
   - If src is in physBoneByRootBone and NOT `IsSimilarChainInPosition(src, newParent, ignores)`, set `childPhysBonesBlockedSet = set(pb.ignoreTransforms)`. The ignores are that PB's non-null ignoreTransforms.
   - Else, if zip, add src to prune.
8. If zip and the blocked set is null, AddMergedBone(src).
9. If zip, go through a snapshot of the children. For each child:
   1. Skip it if it has a MergeArmature.
   2. Start with childNewParent = src and shouldZip = False.
   3. If the name starts with prefix, ends with suffix, and is longer than `len(prefix)+len(suffix)`, set `target = newParent.Find(stripped)`. Then:
      - If the blocked set exists, the child is not in it, and it has no PBBlocker: it's fatal when target is humanoid (warn once). Otherwise `continue`, and the child is not moved.
      - Else, if target exists: set childNewParent = target and shouldZip = True.
   4. `RecursiveMerge(child, childNewParent, shouldZip)`.

A non-zip child still gets SetParent (a no-op), a mangled name and a PBBlocker, but no recursion.

### IsSimilarChainInPosition(a, b, ignores)

True when both hold:
- the squared world distance between a and b is at most 1e-6
- every child of a that is not in ignores, and for which `b.Find(child.name)` exists, is recursively similar

### PruneDuplicatePhysBones

FindOriginalParent walks up while the object is in thisPassAdded. For each obj in prune:
1. Skip obj unless it has a VRCPhysBone and `baseObj = FindOriginalParent(obj)` has one too.
2. Collect baseTargets: `{rootTransform ?? baseObj}` for each of baseObj's PBs.
3. For each of obj's PBs, the target is baseObj if its rootTransform is null, else `FindOriginalParent(rootTransform)`.
4. If that target is in baseTargets, destroy the PB (it becomes dead). Otherwise Retain(pb.transform).

### BoneDatabase

- AddMergedBone sets a bone to True. Retain sets it to False, but only if it's already a key.
- `GetRetargetedBone(b)`:
  1. None if b is null or not a key.
  2. Otherwise walk up while the bone is a key with value True.
  3. None if the bone reached is still a key, else that bone.
- `GetRetargetedBone(b, fallback)` returns b when the result is None.

### RetargetMeshes

- **Which SMRs:** every SMR, inactive ones included, whose bones or rootBone have a non-null retarget.
- **Bind poses:** `bindpose' = dest.worldToLocal · src.localToWorld · bindpose`. The rootBone becomes `GetRetargetedBone(root, fallback)`.
- **Deletion:** go over the True keys in insertion order, recomputing lazily.
  - Skip a bone if its dest is null.
  - Skip a bone that has any component other than a Transform or an MA component (AvatarTagComponent, which includes PBBlocker). Any other MonoBehaviour keeps it.
  - Otherwise move its children to the dest (world kept, appended) and destroy it.
- Animation paths are remapped to the parent.

### Bone Proxy

**Prepass:** `TargetMapping[proxy] = proxy.target` for every proxy, resolved on the ORIGINAL tree.

**Resolving the target:**
1. boneReference LastBone (55) with a blank subPath → None.
2. `"$$AVATAR"` → the avatar root.
3. LastBone → `root.Find(subPath)`.
4. Otherwise the human bone, or None if it's missing. If subPath isn't blank, `bone.Find(subPath)`.

**The pass:** collect the proxies in preorder on the post-merge tree, with `Target = mapping ?? proxy.target`, and record each world position and rotation.

**ProcessProxy** runs only when the target is inside the avatar and is not inside the proxy itself:

    suffix = ""; i = 1
    while target.Find(name + suffix): suffix = f" ({i})"; i += 1
    rename to name + suffix
    SetParent(target, keep world)

**AdjustTransform** runs for every proxy, sorted by avatar-root path. By attachmentMode:
- 0 or 1: localPos 0, localRot identity.
- 2: keep the world position and rotation.
- 3 (KeepRotation): keep the world rotation, localPos 0.
- 4 (KeepPosition): keep the world position, localRot identity.
- With matchScale, localScale becomes 1. Otherwise the scale is whatever SetParent left.

**Errors:** if the target is unresolved, warn and leave the proxy alone. If the target is inside the proxy, warn and skip it.

After moving a proxy, propagate U through its post-MA subtree.

### MoveTo

- Runs in preorder and never re-parents. The defaults are matchPosition = true, matchRotation = true, matchScale = false.
- Sets `position = target.position` and `rotation = target.rotation`.
- For matchScale, after those: `localScale = (TRS(localPos, localRot, 1) · parent.worldToLocal · target.localToWorld).lossyScale`, taking the column lengths.
- Resolve the target through the reference; if it was deleted, warn and skip. Propagate U to the subtree.

### PhysboneBlockerPass (on the final tree)

1. For every PBBlocker tip, append the tip to `dict[ancestor]` for each ancestor from its parent up to and including the avatar root. The tip itself is not included.
2. For every PB: `ignoreTransforms += dict[rootTransform ?? go]`.

MergeArmature adds a PBBlocker to every merged object. So avatar PBs rooted above merged bones ignore those bones.

### AvatarObjectReference.Get

1. An empty referencePath → None.
2. targetObject, if it's inside the avatar.
3. `"$$$AVATAR_ROOT$$$"` → the root.
4. Otherwise `root.Find(path)`. If the result is named "Armature", has a parent and has 0 children, use the first sibling named "Armature" that has children.

### MergeArmature fields

- mergeTarget {referencePath, targetObject}
- prefix and suffix: default "", and the YAML may give None
- legacyLocked, locked and LockMode
- mangleNames: default true
